# Data Science & Analytics Projects

A collection of data analysis and data science projects in Python.

## Projects

### [Retail Price Elasticity Analysis](retail-price-elasticity/)
Estimates how sensitive weekly beer sales are to price for four brands, and whether a price increase would grow or shrink revenue. It compares a naive week-over-week calculation with a log-log regression that controls for seasonality, validated against known true values in a synthetic dataset.
**[▶ Try the interactive price simulator](https://samuelosborn88.github.io/Data-Science/)**, where you pick a brand and move a price slider to see projected volume and revenue.

*pandas · NumPy · matplotlib · regression · pricing analytics · JavaScript*
